📘 Unidad 1

Modelo de Von Neumann, Sistemas Operativos, Numeración, Álgebra de Boole...

Modelo de Von Neumann y Harvard

Descripción

La arquitectura Von Neumann y Harvard representan dos modelos fundamentales en la organización de los computadores y la forma en que procesan la información.

Desarrollo

Durante esta unidad aprendimos cómo funcionan ambas arquitecturas, sus componentes principales, la manera en que almacenan instrucciones y datos, además de las diferencias entre ellas y sus aplicaciones.

Ejemplo

✔ Una computadora personal utiliza la arquitectura Von Neumann, mientras que muchos microcontroladores utilizan la arquitectura Harvard.

Sistemas Operativos

Descripción

Un sistema operativo es el software principal que administra los recursos del computador y permite la comunicación entre el usuario y el hardware.

Desarrollo

En esta unidad conocimos las funciones de un sistema operativo, su importancia, los diferentes tipos y cómo administra la memoria, los archivos y los dispositivos.

Ejemplo

✔ Windows, Linux y macOS son ejemplos de sistemas operativos.

Sistemas de Numeración

Descripción

Los sistemas de numeración permiten representar información utilizando diferentes bases numéricas.

Desarrollo

Se estudiaron los sistemas binario, octal y hexadecimal, además de realizar conversiones entre ellos para comprender cómo la computadora almacena los datos.

Ejemplo

  • Binario → 1010
  • Octal → 12
  • Hexadecimal → A
Aritmética Binaria

Descripción

Es el conjunto de operaciones matemáticas realizadas utilizando únicamente los números 0 y 1.

Desarrollo

Aprendimos a realizar sumas, restas y operaciones básicas en binario, fundamentales para entender el funcionamiento interno de los computadores.

Ejemplo

✔ 1010 + 0011 = 1101

Álgebra de Boole

Descripción

Es un sistema matemático basado en valores lógicos verdadero y falso, utilizado en la electrónica digital.

Desarrollo

Se estudiaron los operadores AND, OR y NOT, comprendiendo cómo funcionan los circuitos lógicos y la toma de decisiones en programación.

Ejemplo

  • 1 AND 1 = 1
  • 1 OR 0 = 1
  • NOT 1 = 0

📗 Unidad 2

Algoritmos, Diagramas de Flujo, Pseudocódigo y Modelado de Problemas.

Algoritmos y sus características

Descripción

Un algoritmo es un conjunto ordenado de pasos que permite resolver un problema.

Desarrollo

Se analizaron las características principales de un algoritmo como precisión, claridad, orden y finitud.

Ejemplo

✔ Algoritmo para calcular el promedio de tres calificaciones.

Diagramas de Flujo

Descripción

Representación gráfica de un algoritmo utilizando símbolos.

Desarrollo

Se aprendió a identificar cada símbolo y representar procesos paso a paso.

Ejemplo

✔ Diagrama para determinar si un número es par o impar.

Pseudocódigo

Descripción

Es una forma sencilla de representar un algoritmo sin depender de un lenguaje de programación.

Desarrollo

Se elaboraron algoritmos utilizando instrucciones fáciles de comprender.

Ejemplo

Inicio
Leer número
Mostrar número
Fin
Modelado de Problemas

Descripción

Proceso mediante el cual se analiza un problema antes de desarrollar la solución.

Desarrollo

Se identificaron entradas, procesos y salidas para resolver distintos casos prácticos.

Ejemplo

✔ Sistema para calcular el sueldo de un trabajador.

Descripción

Permiten realizar cálculos matemáticos, comparaciones y operaciones lógicas dentro de un programa.

Estructuras de Control Condicionales

Descripción

Permiten tomar decisiones dependiendo de una condición.

Desarrollo

Se trabajó con las instrucciones if, elif y else.

Ejemplo

else:

Estructuras de Control Repetitivas

Descripción

Desarrollo

Ejemplo
