📚 Temas de la Unidad 2

🧩 Algoritmos

📖 Descripción

Un algoritmo es un conjunto ordenado y finito de pasos que permite resolver un problema o realizar una tarea.

📝 Desarrollo

Para construir un algoritmo primero se identifica el problema, después se determinan los datos de entrada, el proceso y la salida. Los pasos deben seguir una secuencia lógica y terminar después de un número determinado de instrucciones.

💡 Ejemplo

Algoritmo para sumar dos números: 1) leer A, 2) leer B, 3) calcular A + B y 4) mostrar el resultado.

📋 Características de los Algoritmos

📖 Descripción

Los algoritmos deben cumplir características que permitan comprenderlos y ejecutarlos correctamente.

📝 Desarrollo

Entre sus características principales están ser precisos, definidos, finitos, ordenados y efectivos. Cada paso debe indicar claramente qué hacer y el algoritmo debe producir un resultado.

💡 Ejemplo

Una receta de cocina es un ejemplo cotidiano: contiene ingredientes de entrada, pasos ordenados y un resultado final.

📊 Diagramas de Flujo

📖 Descripción

Un diagrama de flujo representa gráficamente los pasos y decisiones de un algoritmo mediante símbolos.

📝 Desarrollo

Los símbolos más usados son el óvalo para inicio y fin, el rectángulo para procesos, el paralelogramo para entrada o salida y el rombo para decisiones. Las flechas indican el orden del proceso.

💡 Ejemplo

Para saber si un número es positivo: Inicio → Leer número → ¿número > 0? → Sí: mostrar 'positivo' → No: mostrar 'no positivo' → Fin.

📝 Pseudocódigo

📖 Descripción

El pseudocódigo permite escribir un algoritmo con palabras sencillas y estructuras parecidas a las de un programa, sin depender de un lenguaje específico.

📝 Desarrollo

Sirve para planificar una solución antes de programarla. Permite concentrarse en la lógica del problema sin preocuparse todavía por la sintaxis de Python, Java u otro lenguaje.

💡 Ejemplo

Pseudocódigo para saber si una persona es mayor de edad: Leer edad; Si edad >= 18 entonces mostrar 'Mayor de edad'; si no, mostrar 'Menor de edad'; Fin.

💡 Modelado de Problemas

📖 Descripción

Modelar un problema significa analizarlo y representarlo de manera organizada para encontrar una solución.

📝 Desarrollo

Primero se identifica qué se necesita resolver. Luego se determinan las entradas, el procesamiento y las salidas. Finalmente se diseña un algoritmo, diagrama o pseudocódigo que represente la solución.

💡 Ejemplo

Para calcular el promedio de tres notas: entradas = nota1, nota2 y nota3; proceso = (nota1 + nota2 + nota3) / 3; salida = promedio.
