Algoritmos y sus características

Descripción

Un algoritmo es un conjunto ordenado y finito de pasos que permite resolver un problema o realizar una tarea específica.

Desarrollo

Durante esta unidad se estudiaron las principales características de un algoritmo: precisión, claridad, secuencia lógica y finitud. También se analizaron ejemplos prácticos para comprender su importancia en la programación.

Ejemplo

Inicio

Leer dos números

Sumarlos

Mostrar el resultado

Fin
Diagramas de flujo como herramienta de modelación de algoritmos

Descripción

Los diagramas de flujo representan gráficamente los pasos de un algoritmo mediante símbolos estandarizados.

Desarrollo

Se aprendió el significado de cada símbolo y la forma correcta de representar procesos para facilitar el análisis y la solución de problemas.

Ejemplo

✔ Un diagrama para determinar si un número es par o impar mediante una decisión.

Pseudocódigo: una herramienta de palabras útil

Descripción

El pseudocódigo es una forma de representar un algoritmo utilizando un lenguaje sencillo y estructurado, sin depender de un lenguaje de programación específico.

Desarrollo

Se aprendió a escribir algoritmos utilizando instrucciones claras y ordenadas, facilitando el diseño de programas antes de codificarlos.

Ejemplo

Inicio

Leer nombre

Mostrar "Bienvenido", nombre

Fin
Modelado de Problemas

Descripción

El modelado de problemas consiste en analizar una situación para identificar las entradas, procesos y salidas necesarias para encontrar una solución.

Desarrollo

Durante esta unidad se practicó el análisis de distintos problemas, identificando la información necesaria y diseñando algoritmos que permitieran resolverlos de forma lógica y organizada.

Ejemplo

✔ Diseñar un algoritmo que calcule el promedio de tres calificaciones ingresadas por el usuario.
