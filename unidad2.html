🧩 Algoritmos

Descripción

Un algoritmo es un conjunto de pasos ordenados y finitos que permiten resolver un problema o realizar una tarea.

Desarrollo

Los algoritmos deben seguir una secuencia lógica para obtener un resultado correcto. Son la base de cualquier programa informático.

Ejemplo

Algoritmo para sumar dos números:
1. Leer A.
2. Leer B.
3. Sumar A + B.
4. Mostrar el resultado.

📋 Características de los Algoritmos

Descripción

Todo algoritmo debe cumplir ciertas características para funcionar correctamente.

Desarrollo

Las principales características son:

  • Preciso.
  • Definido.
  • Finito.
  • Ordenado.
  • Eficiente.

Ejemplo

Una receta de cocina es un algoritmo porque sigue pasos específicos para obtener un resultado.

📊 Diagramas de Flujo

Descripción

Son representaciones gráficas de un algoritmo utilizando símbolos estandarizados.

Desarrollo

Permiten visualizar fácilmente el proceso de solución de un problema antes de programarlo.

Ejemplo

Inicio → Leer número → ¿Es mayor que 0? → Mostrar resultado → Fin.

📝 Pseudocódigo

Descripción

Es una forma de escribir algoritmos utilizando lenguaje sencillo, sin depender de un lenguaje de programación específico.

Desarrollo

Facilita la planificación del programa antes de escribir el código real.

Ejemplo

Inicio
Leer edad
Si edad ≥ 18 Entonces
  Mostrar "Mayor de edad"
Si no
  Mostrar "Menor de edad"
Fin

💡 Modelado de Problemas

Descripción

Consiste en analizar un problema para encontrar la mejor forma de resolverlo mediante un algoritmo.

Desarrollo

Se identifican los datos de entrada, el proceso y la salida esperada antes de desarrollar el programa.

Ejemplo

Problema: Calcular el promedio de tres notas.

Entrada: Nota1, Nota2 y Nota3.
Proceso: (Nota1 + Nota2 + Nota3) / 3.
Salida: Promedio.
