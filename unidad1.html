Modelo de Von Neumann y Harvard

Descripción

Son dos arquitecturas utilizadas para organizar el funcionamiento interno de un computador. Cada una define cómo se almacenan y procesan las instrucciones y los datos.

Desarrollo

La arquitectura de Von Neumann utiliza una sola memoria para guardar tanto datos como instrucciones, mientras que la arquitectura Harvard utiliza memorias separadas, permitiendo un procesamiento más eficiente.

Ejemplo

Un computador personal normalmente utiliza la arquitectura Von Neumann, mientras que muchos microcontroladores utilizan la arquitectura Harvard.

Sistemas Operativos

Descripción

Es el software encargado de administrar los recursos del computador y permitir la interacción entre el usuario y el hardware.

Desarrollo

Durante esta unidad se estudiaron sus funciones, tipos, administración de archivos, memoria y dispositivos.

Ejemplo

Windows, Linux y macOS son ejemplos de sistemas operativos.

Sistemas de Numeración y Conversiones

Descripción

Los sistemas de numeración permiten representar la información utilizando diferentes bases como binario, octal y hexadecimal.

Desarrollo

Se realizaron conversiones entre sistemas de numeración para comprender cómo las computadoras almacenan la información.

Ejemplo

  • 1010₂ = 10₁₀
  • 15₁₀ = F₁₆
  • 8₁₀ = 10₈
Aritmética Binaria

Descripción

La aritmética binaria consiste en realizar operaciones matemáticas utilizando únicamente los dígitos 0 y 1. Es la base del funcionamiento interno de las computadoras.

Desarrollo

En esta unidad aprendimos a realizar sumas, restas y otras operaciones en sistema binario, comprendiendo cómo el computador procesa la información digital.

Ejemplo

   1010
+  0011
-------
   1101
Álgebra de Boole

Descripción

El álgebra de Boole es un sistema matemático que trabaja con dos valores lógicos: verdadero (1) y falso (0). Es fundamental para la electrónica digital y la programación.

Desarrollo

Se estudiaron las operaciones lógicas AND, OR y NOT, así como las leyes básicas del álgebra de Boole y su aplicación en circuitos digitales y estructuras condicionales.

Ejemplo

Operación Resultado
1 AND 1 1
1 OR 0 1
NOT 1 0
