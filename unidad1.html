Modelo de Von Neumann y Harvard

📖 Descripción

Son dos modelos de arquitectura utilizados para organizar los componentes y el funcionamiento de un computador.

📝 Desarrollo

El modelo de Von Neumann utiliza una memoria única para almacenar tanto las instrucciones como los datos. El procesador obtiene de esa memoria las instrucciones que debe ejecutar y los datos necesarios. En cambio, la arquitectura Harvard utiliza memorias separadas para las instrucciones y para los datos. Esto permite acceder a ambos de manera independiente y puede mejorar el rendimiento.

💡 Ejemplo

Un computador personal puede utilizar una arquitectura basada en Von Neumann, mientras que muchos microcontroladores utilizan una arquitectura Harvard.

Sistemas Operativos

📖 Descripción

Un sistema operativo es el software principal que administra los recursos de un computador y permite que otros programas funcionen.

📝 Desarrollo

El sistema operativo administra la memoria, el procesador, los archivos, los dispositivos de entrada y salida y los programas. También proporciona una interfaz para que el usuario pueda interactuar con el computador.

💡 Ejemplo

Algunos sistemas operativos conocidos son Windows, Linux, macOS, Android e iOS.

Sistemas de Numeración y Conversiones

📖 Descripción

Los sistemas de numeración permiten representar cantidades mediante diferentes símbolos y reglas.

📝 Desarrollo

En informática se utiliza principalmente el sistema binario, que utiliza los números 0 y 1. También se utilizan el sistema octal y hexadecimal para representar información de una manera más compacta. El sistema decimal utiliza diez símbolos, del 0 al 9.

💡 Ejemplo

Un número decimal puede convertirse a binario. 

Decimal:     10

Binario:     1010

Octal:       12

Hexadecimal: A
Aritmética Binaria

📖 Descripción

La aritmética binaria consiste en realizar operaciones matemáticas utilizando solamente los valores 0 y 1.

📝 Desarrollo

Las operaciones binarias principales son suma, resta, multiplicación y división. Estas operaciones son fundamentales porque los computadores representan y procesan la información mediante bits.

💡 Ejemplo

Una suma binaria sencilla: 

   1010
 + 0011
 ------
   1101

Por lo tanto: 1010 + 0011 = 1101

Álgebra de Boole

📖 Descripción

El álgebra de Boole es un sistema matemático utilizado para trabajar con valores lógicos, principalmente 0 y 1.

📝 Desarrollo

Es muy importante en informática porque permite representar operaciones lógicas y diseñar circuitos digitales. Sus operadores principales son AND, OR y NOT.

💡 Ejemplo

AND

1 AND 1 = 1
1 AND 0 = 0


OR

1 OR 0 = 1
0 OR 0 = 0


NOT

NOT 1 = 0
NOT 0 = 1
