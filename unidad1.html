🖥 Modelo de Von Neumann y Harvard

Descripción

Son dos arquitecturas utilizadas para organizar el funcionamiento de un computador.

Desarrollo

El modelo de Von Neumann utiliza una sola memoria para almacenar datos e instrucciones, mientras que el modelo Harvard utiliza memorias independientes para cada una, permitiendo ejecutar procesos con mayor rapidez.

Ejemplo

La mayoría de computadoras personales utilizan la arquitectura Von Neumann, mientras que muchos microcontroladores utilizan la arquitectura Harvard.

💻 Sistemas Operativos

Descripción

Es el software encargado de administrar el hardware y los recursos del computador.

Desarrollo

Gestiona la memoria, los dispositivos, los archivos y permite ejecutar programas de forma eficiente.

Ejemplo

Windows 11, Ubuntu Linux y macOS.

🔢 Sistemas de Numeración

Descripción

Son diferentes formas de representar cantidades mediante símbolos.

Desarrollo

En informática se utilizan principalmente los sistemas binario, octal, decimal y hexadecimal para representar información.

Ejemplo

Decimal: 25 → Binario: 11001 → Hexadecimal: 19.

➕ Aritmética Binaria

Descripción

Consiste en realizar operaciones matemáticas utilizando únicamente los dígitos 0 y 1.

Desarrollo

Se aplican reglas de suma, resta, multiplicación y división binarias para procesar información dentro del computador.

Ejemplo

1010 + 0011 = 1101

⚙ Álgebra de Boole

Descripción

Es un sistema matemático basado en valores lógicos (0 y 1).

Desarrollo

Permite diseñar circuitos digitales mediante operadores lógicos como AND, OR y NOT.

Ejemplo

1 AND 1 = 1
1 AND 0 = 0
1 OR 0 = 1
