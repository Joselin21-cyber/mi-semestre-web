💻 Lenguajes y Paradigmas de Programación

Descripción

Los lenguajes de programación permiten crear programas mediante instrucciones que la computadora puede interpretar.

Desarrollo

Existen diferentes paradigmas como programación estructurada, orientada a objetos, funcional y lógica. Cada uno ofrece distintas formas de resolver problemas.

Ejemplo

Python es un lenguaje multiparadigma porque permite programar de forma estructurada y orientada a objetos.

🐍 Introducción a Python

Descripción

Python es un lenguaje de programación de alto nivel, sencillo y fácil de aprender.

Desarrollo

Se utiliza para crear aplicaciones, páginas web, inteligencia artificial, análisis de datos y automatización.

Ejemplo

print("Hola Mundo")
➕ Operadores Algebraicos, Relacionales y Lógicos

Descripción

Los operadores permiten realizar cálculos y comparar valores dentro de un programa.

Desarrollo

Algebraicos: +, -, *, /, %
Relacionales: ==, !=, >, <, >=, <=
Lógicos: and, or, not

Ejemplo

a = 10
b = 5

print(a + b)
print(a > b)
print(a > 5 and b < 10)
🔀 Estructuras Condicionales

Descripción

Permiten tomar decisiones dependiendo de si una condición es verdadera o falsa.

Desarrollo

Las más utilizadas son if, elif y else.

Ejemplo

edad = 18

if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")
🔁 Estructuras Repetitivas

Descripción

Permiten repetir un conjunto de instrucciones varias veces.

Desarrollo

Las estructuras más comunes son for y while.

Ejemplo

for i in range(5):
    print(i)
