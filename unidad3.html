Lenguajes y Paradigmas de Programación

Descripción

Los lenguajes de programación permiten crear programas que resuelven diferentes problemas mediante instrucciones que la computadora puede interpretar.

Desarrollo

Se estudiaron los diferentes paradigmas de programación, como el estructurado, orientado a objetos y funcional, comprendiendo sus características y aplicaciones.

Ejemplo

Ejemplos de lenguajes: Python, Java, C++, JavaScript y C#.

Introducción a la Programación en Python

Descripción

Python es un lenguaje de programación sencillo, versátil y ampliamente utilizado para desarrollar aplicaciones, automatizar tareas y analizar datos.

Desarrollo

Durante esta unidad se aprendió la sintaxis básica de Python, la creación de variables, la impresión de datos en pantalla y la estructura de un programa.

Ejemplo

print("Hola Mundo")
Operadores Algebraicos, Relacionales y Lógicos

Descripción

Los operadores permiten realizar cálculos matemáticos, comparar valores y combinar condiciones para tomar decisiones dentro de un programa.

Desarrollo

Se trabajó con operadores aritméticos (+, -, *, /), relacionales (>, <, ==) y lógicos (AND, OR, NOT), aplicándolos en diferentes ejercicios prácticos.

Ejemplo

a = 10
b = 5

print(a + b)
print(a > b)
Estructuras de Control Condicionales

Descripción

Las estructuras condicionales permiten que un programa tome decisiones dependiendo de si una condición es verdadera o falsa.

Desarrollo

Se aprendió a utilizar las instrucciones if, elif y else para controlar el flujo de ejecución de un programa según diferentes condiciones.

Ejemplo

nota = 8

if nota >= 7:
    print("Aprobado")
else:
    print("Reprobado")
Estructuras de Control Repetitivas

Descripción

Las estructuras repetitivas permiten ejecutar un bloque de instrucciones varias veces hasta que se cumpla una condición o durante un número determinado de repeticiones.

Desarrollo

En esta unidad se estudiaron los ciclos for y while, aprendiendo a utilizarlos para automatizar tareas repetitivas y recorrer colecciones de datos.

Ejemplo

for i in range(5):
    print(i)
