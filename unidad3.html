📚 Temas de la Unidad 3

💻 Lenguajes y Paradigmas de Programación

📖 Descripción

Los lenguajes de programación permiten escribir instrucciones para crear software, mientras que los paradigmas son formas de organizar y pensar las soluciones.

📝 Desarrollo

Existen paradigmas como el estructurado, orientado a objetos, funcional y lógico. Un mismo lenguaje puede soportar más de un paradigma y ofrecer distintas formas de resolver un problema.

💡 Ejemplo

Python es multiparadigma: permite escribir programas estructurados y también crear clases y objetos mediante programación orientada a objetos.

🐍 Introducción a Python

📖 Descripción

Python es un lenguaje de alto nivel conocido por su sintaxis clara y por ser utilizado en muchas áreas de la tecnología.

📝 Desarrollo

Se emplea en desarrollo web, automatización, análisis de datos, inteligencia artificial y educación. Su sintaxis permite comenzar a programar con instrucciones relativamente sencillas.

💡 Ejemplo

Un primer programa en Python puede mostrar un mensaje usando: print('Hola Mundo').

➕ Operadores Algebraicos, Relacionales y Lógicos

📖 Descripción

Los operadores permiten realizar cálculos, comparar valores y combinar condiciones dentro de un programa.

📝 Desarrollo

Los operadores algebraicos o aritméticos incluyen +, -, *, /, %, // y **. Los relacionales permiten comparar valores como ==, !=, >, <, >= y <=. Los lógicos incluyen and, or y not.

💡 Ejemplo

Si a = 10 y b = 5, entonces a + b produce 15, a > b produce True y a > 5 and b < 10 también produce True.

🔀 Estructuras Condicionales

📖 Descripción

Las estructuras condicionales permiten que un programa tome decisiones según se cumplan o no determinadas condiciones.

📝 Desarrollo

En Python se utilizan principalmente if, elif y else. El programa evalúa una condición y ejecuta el bloque correspondiente.

💡 Ejemplo

Para determinar la mayoría de edad: if edad >= 18: mostrar 'Mayor de edad'; else: mostrar 'Menor de edad'.

🔁 Estructuras Repetitivas

📖 Descripción

Las estructuras repetitivas permiten ejecutar varias veces un conjunto de instrucciones.

📝 Desarrollo

En Python las más utilizadas son for y while. for suele utilizarse cuando se conoce o recorre una cantidad de elementos, mientras que while repite mientras una condición sea verdadera.

💡 Ejemplo

Con for i in range(5), el programa puede recorrer los valores 0, 1, 2, 3 y 4 y mostrar cada uno.
